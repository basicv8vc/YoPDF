# YoPDF Sticker Assets Manifest

This file is a **technical inventory** of the sticker artwork shipped in the
YoPDF application bundle. It is not a license, a sublicense, or a copyright
notice. YoPDF remains licensed under the repository's existing Apache-2.0
`LICENSE`, which is unchanged.

## Provenance

The 20 illustrations were generated by the project owner with **GPT Image**
(OpenAI image generation). They were then prepared as 256×256 transparent PNGs
for the application. No claim of exclusivity or uniqueness is made; the images
are recorded here so their identity, packaging path, and bytes can be verified.

The images are the original artwork used by ShuaMac. They were copied from the
read-only ShuaMac checkout only after the project owner explicitly authorized
their inclusion in YoPDF. The 33 MB original-resolution artwork and the private
generation prompts are deliberately **not** part of this repository.

no image. Every illustration is packaged exactly once as a single `universal`

## Verification

From the repository root:

```bash
macos/scripts/verify-sticker-assets.sh
```

The script verifies each SHA-256 above against the source asset, then checks that
the built application bundle contains the 20 sticker assets exactly once and does
not contain the original-resolution artwork or generation prompts.
